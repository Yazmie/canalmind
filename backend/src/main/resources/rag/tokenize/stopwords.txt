# BM25 通道的停用词表（第 2 周第 4 项）
#
# 格式：一行一个词；`#` 开头的行是注释，空行忽略。
# ⚠️ 与本目录的 shipping-dictionary.txt 格式**不同**：
#    那个文件由 jieba 的 loadUserDict 直接解析，**不允许注释行**（见
#    build_shipping_dictionary.py 文件头）。本文件由 JiebaShippingTokenizer
#    自己解析，故可以带注释。
#
# ── 选取口径（刻意保守，宁少不多）────────────────────────────────────────────
# 只剔除**纯功能词/结构词**——它们在 541 个 chunk 里几乎篇篇出现，
# 对区分度贡献≈0，却会撑大倒排表、抬高 df、稀释 idf。
#
# ⛔ 刻意**不**剔除的（这些看着像功能词，实际带业务含义）：
#    应当 / 应该 / 可以 / 不得 / 必须 / 需  —— 规则语料的**规范性模态**，
#        「不得退费」与「可以退费」是相反结论，剔除会直接毁掉区分度。
#    以上 / 以下 / 超过 / 不超过 —— 尺度类条款的判据。
#    日 / 天 / 米 / 吨 / 元 / 次 —— 计费单位与尺度量纲。
#    港 / 船 / 闸 / 货 / 费 —— 单字领域词干。
#
# ── 效果与复核 ───────────────────────────────────────────────────────────────
# 停用词表**参与档案指纹**（rag_token_profile.stopwords_sha256）：
# 改一个词就会让指纹变化，从而**拒绝重灌**，必须先新建档案——
# 这是刻意的，否则"两次评测跑分不同"将无法归因到具体是哪一版停用词。
# 复核命令见 docs/进度看板.md §3.4。
