# 评测集自身的错误不会报错，只会让"指标好看"

> 类别：[数据一致性](README.md) ｜ 返回总索引：[../README.md](../README.md)

| 项 | 内容 |
|---|---|
| **问题** | Golden Set L2（40 条评测题）是**一切检索指标的基准**，但它的错误**不会以报错的形式暴露**——只会以"**指标好看但与事实不符**"的形式暴露。这与[校验器输出顺序导致错误被吞](../工程方法/校验器输出顺序导致错误被吞.md)同属"绿得是假的"，区别是这次**被校验的对象是基准本身**。 |
| **三类风险** | ①**gold chunk id 抄错**（16 位手写，极易看错一位）→ 表现为"某个 chunk 永远召不回"，会被**误读成检索缺陷**；②**分布失衡**（题型 / 主题类扎堆）→ 知识库《AI 应用评测体系》第 100 行明说"样本分布往往比总量更先决定评测能否发现问题"，而**分布失衡不会让任何脚本变红**；③**题面照抄条款用词** → 反向生成最容易犯的错：题面与原文高度重合时检索"轻松命中"，造成**系统性高估召回**，并直接污染第 4 周消融结论（决策 C-28 ④ 已明令禁止沿用标题原词）。 |
| **怎么做的** | 新增 `backend/scripts/verify_golden_set.py`，把三类风险变成可执行检查。检查项清单在该脚本 **docstring 的「检查项」小节**（共 **10 项**：结构完整 / 编号 `L2-0NN` 唯一且连续 / 32 `dev` + 8 `holdout`（且保留集跨 ≥4 题型、≥4 主题类）/ 题型 T1–T6 各 ≥6 条 / 主题类 A–G 各 ≥4 条 / **gold chunk 在库中真实存在**且其文档编号落在该题主题类范围内 / gold 正文非空 / 反照抄 / 已知限制项自证 / **可接受等价块**（v2 新增））。⚠️ **锚点认小节名与字段名，不认行号**——脚本随轮次增长，行号已经位移过一次。 |
| **首次运行的收获** | **当场抓出 7 项错误**：6 项反照抄 + 1 项**我自己写错的断言**（见[规则过严会把正确的东西判成错的](../工程方法/规则过严会把正确的东西判成错的.md)）。⚠️ 首次运行的逐项输出**当时未落盘**，现已无法复现该 7 项明细；可核对的是修好后的 PASS 快照 `docs/评测报告/golden-l2-validation.json`（读它的 `failures` 字段——为空数组即无错误）。 |
| **当前状态（可复现）** | `python backend/scripts/verify_golden_set.py` 实测 **`failures` 为空、`warnings` 9 条**（反照抄警告 8 + `gold 跨文档` 1），`goldChunkCount` **41**（含 `L2-027` 的两个 gold）全部命中库表，退出码 0。分母一并落盘：split 32 / 8，题型 6/8/7/7/6/6，主题类 6/7/6/4/6/4/7。⚠️ **`datasetSha256` 故意不写死在这里**——数据集一旦修订（v2 等）任何字面量 sha 都会立刻失效，而读者无从判断该锚点是「过期」还是「被改动」。要核对就现场跑脚本读 `docs/评测报告/golden-l2-validation.json` 的 `datasetSha256` 字段（本条目只承诺「命令可通过」，不承诺某个哈希值）。 |
| **修订之后（v2，2026-09-21）** | 对抗式复核查出的 23 处待修订，经**逐条核验**后按全套修订包落改（决策 **C-29**），数据集升 **v2**（v1 原样保留供对照），校验快照随之更新为 `golden-l2-validation.json`（`dataset` 字段指向 `golden-l2-v2.json`）。**三类豁免全部逐条打印并落进机读产物**（`termExemptions` / `identifierExemptions` / `crossClassGoldExemptions`）——见[规则过严会把正确的东西判成错的](../工程方法/规则过严会把正确的东西判成错的.md)。⚠️ **修订评测集会改变指标**，所以「改完指标怎么变才算健康」本身也立了一条纪律，见[改评测集后指标怎么变才算健康](改评测集后指标怎么变才算健康.md)。 |
| **业务含义** | **评测集是尺子；尺子自己错了，后面所有"提升 / 回退"的判断都失去意义**——而且这种错不报错，只会让每次实验都"看起来在进步"。它和语料、数据库种子数据一样，属于**要被校验的数据资产**，而不是"天然的真理"。 |
| **可能被追问** | "分布失衡为什么危险？"→ 它不触发任何断言，只会让某一类能力**从未被考到**，"指标不错"于是掩盖了"这块根本没测"。"为什么不靠人工多看几遍？"→ 40 条能看，400 条看不到分布；**把约定做成机器检查**才随规模成立。 |
