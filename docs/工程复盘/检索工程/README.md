## 本类共同教训

**性能优化的近似结构，会用"结果完整性"换速度，而且静默地换。**

所以验收检索链路时：
- 不能只看"走的什么索引"，必须**对账结果条数**
- 任何"**带过滤 + Top-K**"的场景都要**专门测**
- **近似索引的副作用，要用"结果数对不对"来守护**，而不是用"计划好不好看"来判断
