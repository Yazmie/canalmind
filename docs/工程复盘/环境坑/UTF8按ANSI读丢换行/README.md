# UTF8按ANSI读丢换行（主题索引）

> 类别：[环境坑](../README.md) ｜ 返回总索引：[../../README.md](../../README.md)

**这一主题讲什么**：**PowerShell 5.1 的 `Get-Content` 不带 `-Encoding` 时按 ANSI／系统代码页解码**（本机默认代码页 **GBK**）——
GBK 是双字节编码，行尾最后一个中文字的字节与紧随其后的 **LF（0x0A）** 被拼成一个双字节序列时，**那个 LF 就被吞掉**：
**换行凭空变少，而且一个字都不报错**。本条按 `AGENTS.md` §8.3 的递归规则（单条超过约 40 行 ⇒ 就地新建**主题子目录**、拆成多条）拆开。
