# 用「整层重判」清空应答行不通

> **一句话**：我断言"把 L3/L5/L6 **整层重判一遍**就能清掉判分端的空应答、把三层都升级为**点估计**"，
> 并据此向用户报了预估、拿了批准；**实测证伪**——空应答**不是"某几道题"的属性，而是每次判分各掷一次的随机事件**，
> 重判后只是"空的那道题换了题号"（L3 清零、**L5 仍 2/20、L6 仍 1/15**）。
> ⇒ 目标"三层都成点估计"**只达成 1/3**，代价是 **55 次付费调用** + **L6 严格口径反而降了 1 题**。

## 我当时凭什么这么断言（现在看是错的推理链）

| 我的推理 | 缺的那一步 |
|---|---|
| 空应答只出现在**少数几道题**上（L3 1/20、L5 2/20、L6 1/15） | 我**没有**先问：这"几道题"是**固定的题号**，还是**每次换一批**？ |
| ⇒ 所以它们是"这几道题太长的偶发事故" | 这个"所以"是我自己加的——**样本只有一次观测**，它撑不起任何稳定性结论 |
| ⇒ 所以**换一批答案/重判一轮**就会好转 | 重判**不改变题面、预算、模型、提示词**（C-60 明确登记"四项都没变"）⇒ 它检验的是**非确定性**，不是缺陷 |

## 实测否证（`DECISIONS.md` C-60 逐题对照，run `w5-2026-09-22-judge-recheck`）

| 方向 | 题号 | 重判前 → 重判后 |
|---|---|---|
| **旧空 → 新正常**（3 题） | `L3-006` | `0/0/0`（`parseOk=false`）→ `1/3/3` |
| | `L5-014` | 空 → `1/5/5` |
| | `L6-005` | 空 → `3/4/2` |
| **旧正常 → 新空**（2 题） | `L5-004` | `3/4/3` → `0/0/0` |
| | `L6-010` | `1/2/1` → `0/0/0` |

⇒ 空应答**双向流动**：该来的会好、好的会空。这正是"随机游走"的指纹。

**机制**（`JudgeRunCli` 的 `JUDGE_MAX_TOKENS` javadoc 早就写下了）：判分预算（4096）**被推理吃掉、正文没剩额度** ⇒
回复为空。而"推理吃掉多少"本身依模型内部状态而变 ⇒ **空应答天然不稳定**。
⛔ 与"答错"是两件事：它的 0 分含义是**未取得有效评分**，不是"答得差"（`LlmJudge` 类注释第 3 条）。

## 代价与后果（⛔ 都写下来，不只写"学到了"）

- **55 次付费调用**换来一条"此路不通"的结论（L3 19 + L5 20 + L6 15 + 冒烟 1）。
- ⚠️ **L6 严格口径反而从 6/15 降到 5/15**（`L6-013` 的 faithfulness 5→3 翻转，属判分非确定性，
  已逐题归因）。⇒ **"重跑一次"不保证数字变好**，只保证"换一批噪声"。
- ✅ 唯一真实的收获：**L3 升为点估计（18/20 = 0.9000）**，且它的空应答**恰好清零**——⚠️ 但要写清：
  **这是运气，不是方法**。同一个"方法"在 L5/L6 上就没成立。

## 更正后的结论

1. **能清掉空应答的只有机制改动**：给判分器加"**空 ⇒ 重试 1 次**"（**C-62**，用户随后批准）；
   而"重判一轮"这类**重采样**做法，期望上只是把空应答**重新洗一遍**。
2. ⚠️ 即便加了重试，**重试也可能再空**（同一机制）⇒ 该层通过率**仍按下界**引用，
   只有在**空应答真的为 0**时才允许说"点估计"。⇒ 结论必须以**实测计数**为准，不以"我们加了重试"为准。

## 可迁移的方法教训（这才是要讲的部分）

1. **别把"症状描述"升格成"机制结论"。** "空应答集中在少数几道题"是**一次观测的分布**；
   "这些问题本身有毛病"是**机制**。前者推不出后者——**要判定稳定性，就得重复观测**。
2. ⚠️ **花 55 次付费之前，本可以先花 1–3 次做"稳定性探针"**：同一道**已知会空**的题连判 2–3 次，
   看空应答是否复现。**探针成本 <1% 验证成本**，却能直接否掉整条路线。
   ⇒ 与 [环境坑/PowerShell脚本的反引号陷阱](../环境坑/PowerShell脚本的反引号陷阱.md) 同一条：
   **把可能失败的检查放在最便宜的地方**（那里是"付费脚本的失败点不许留在最后一步"）。
3. **"重跑一次"要写明它检验什么。** 同一输入、同预算、同模型下的重跑，检验的是**非确定性**；
   要检验**缺陷是否修好**，必须改掉至少一个变量。
