# 把未决的决策当成了缺证据

> **一句话**：我在会话里断言「**D8（改写策略）待决 ⇒ 消融至少一臂缺**」，
> 用户据此决定"规格书 L653 先不勾"。取证后发现——**那一臂早就出数了**：
> 看板两处明写「消融实验 **6/6** 全部有数」并列出 `+Query Rewrite`。
> 我把**"策略族怎么选还没定"**与**"这一臂没跑"**当成了同一件事。

## 事实链（可复核）

| 时间 | 发生了什么 | 锚点 |
|---|---|---|
| 我先说 | 「L653 消融全套 ⛔ 不建议勾：**D8 仍待决 ⇒ 至少一臂缺**」 | 本会话对话 |
| 用户据此裁定 | 「L653 不勾并注明」 | 同上 |
| 我取证 | 看板写着 **消融 6/6 全部有数**，且**明列 `+Query Rewrite` 臂** | `docs/进度看板.md` 第 13 行、第 414 行 |
| 我更正 | 主动报告"我上一条判断是错的"，重新请用户裁定 | 本会话对话 |
| 用户改判 | 「改勾上，并注明依据」 | 同上 |
| 留痕 | 规格书 L653 勾选，并在同一行写明"此前判断不成立" | `docs/平陆运河…项目规格与执行清单.md` 第 653 行；提交 `188aff6` |

## 错在哪（两个独立错误叠加）

1. **逻辑错误：用"决策未决"推断"证据缺失"。**
   `D8` 问的是"检索类改写用**哪种策略族**"；而消融里的 `+Query Rewrite` 臂只需要**一个已配置的改写器**
   就能出数——**两者之间没有逻辑蕴含**。我把"上游还有一个开放决策"直接读成了"下游这一臂不存在"。
2. **流程错误：先断言，后取证。**
   ⚠️ 更要紧的是——**证据当时就在我手里**（看板那两行我此前读过、还引用过它的 §9 出处），
   但我在给出判断前**没有回去核对**。这不是"信息不足"，是"**没有把断言挂在产物上**"。

## 代价与收获

- **代价很小**（一次重新确认 + 一处勾选更正），但它暴露的形态很危险：
  这类错误给出的是**"欠报"**而不是"虚报"——**规格书会长期少一个已完成的勾**，
  而"少勾"通常被当成"谦虚"，于是**没人会去质疑它**。⚠️ 结论：**欠报与虚报同样是失真**。
- 收获一条硬规矩：⛔ **任何"某臂缺 / 某项未做"的断言，必须能指出"缺在哪一行、哪份产物"**；
  ⛔ **不得以"上游决策未定"作为"证据不存在"的理由**——那是两件事。

## 与同族条目的关系

- 本条属"**归因错**"而非"数据错"：与 [不是结论错了是归因错了](不是结论错了是归因错了.md) 同型。
- 检出方式与 [断言某字段独有而其实只看了样例](断言某字段独有而其实只看了样例.md) 相同：
  **去看产物/文档本身**，而不是继续推理。
