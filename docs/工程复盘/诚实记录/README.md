## 为什么单独立一类

因为这类内容**最容易被自己删掉**——"我犯过的错"看起来不像成果。
但面试官问"你犯过什么错 / 这项目有什么不足"时，**能具体、已修正、并固化成流程地回答**，
比说"我比较细心"有力得多。

**纪律**：发现自己的错误结论后，**必须在本目录留痕，不得静默改掉**（见 `AGENTS.md` §8.2）。
