# 量程不足会把「被配置掐死」记成「能力不足」

> 主题索引 ｜ 分类：[工程方法](../README.md) ｜ 总索引：[../../README.md](../../README.md)

`max_tokens` 与 `timeout` 不是「调参」，是「**量程**」：量程不足时调用确实会失败，
但产物**只会说「降级了」**——从产物读出来就成了「模型能力不足」。本主题收录这条结论的
顶部速查表、实测数字、产物与 banner 的取证方式、修复前后的对照，以及开跑前的检查清单。
