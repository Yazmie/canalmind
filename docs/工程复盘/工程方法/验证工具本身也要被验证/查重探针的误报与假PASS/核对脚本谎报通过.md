## 实测例子 ⑥（同一会话）：我自己写的核对脚本，是一个**假 PASS**

> 上一条是探针**误报**；这一条更贵——检查器**谎报通过**。误报会让人去查一个不存在的问题，**假 PASS 会让人以为问题已经查完了**。

| 项 | 内容 |
|---|---|
| **当时我做了什么** | 为核对数据包里那张**三臂对照表**（`ctx10-norank` / `ctx10-rerank` / `ctx30-rerank`，含 `HitRate@3` 等指标行）的数字与产物是否一致，我当场写了一个 **Python 一次性核对脚本**。⚠️ 这里用**表里的臂名**做锚点而不是小节号——因为本轮恰好出过「小节号差点被我编重」的事（见上一条⑤），**小节号是这里最不稳的锚点**。 |
| **工具给了我什么** | 两样**互相打脸**的东西：① 正文里打印出**一堆「不符」**；② **最后一行**打印 `核了 66 格，不符 0 格`。 |
| **我据此发出了什么结论** | 先被那堆「不符」引向「**有一批数字对不上**」；再看末行，又会被引向「**都对上了**」。⚠️ **同一份输出同时支持两个相反的结论**——这本身就说明它不是一把尺子。 |
| **真相是什么** | 脚本有两个缺陷：<br>① **没有限定范围**——它把文档里**别的小节**（四路对照表）的表行也拉进来比对，于是那堆「不符」**全是误报**；<br>② **更严重：最后一行是无条件打印**——`0` 是**写死在打印语句里的字面量**，**不管前面有没有不符，它永远说「不符 0 格」**。<br>⇒ 这个脚本**既会误报、也会谎报通过**。⚠️ 发现②的方式是**我自己读输出**：前面明明打印了 ⛔ 行，末行却说 0 不符——**如果我只扫末行，它会一直绿下去**。 |
| **修法（已落地；逐字片段见下方代码块）** | ① **先断言定位到了正确对象**；② **限定到目标小节**（只比目标表格，不碰别的小节）；③ **真实计数**：比对不符时 `mism += 1`，末行由 `mism` 渲染；④ 加**自证断言**：核到的格数太少，就判「**检查器失效**」，而不是判「都对了」。 |

**修好之后的四行关键改动（逐字片段，非整脚本）**：

```python
assert "ctx10-norank" in sec                   # ① 先证明我定位到了正确对象
mism += 1                                      # ③ 真实计数（不再写死 0）
print(f"核了 {checked} 格，不符 {mism} 格")      # 末行由 mism 生成
assert checked >= 20                           # ④ 自证：核到的格数太少 ⇒ 判「检查器失效」
```

| 项 | 内容 |
|---|---|
| **⭐ 修好检查器之后，它立刻抓到了我自己的一个真错** | 变成**真检查器**之后，**同一批数据**当场查出：我在数据包里把 `ctx10-norank` 这一臂的 `HitRate@3` 写成了 **0.8125**，而产物里是 **0.8438**（`backend/target/eval/metrics-item6-ctx10-norank.json` 的原始值 `0.84375`）⇒ **已改**。<br>**这就是「假 PASS 被修掉之后立刻产生价值」的直接证据**：**同一个脚本、同一批数据**——修之前它说「不符 0 格」（把真错藏在绿里），修之后它**当场把真错指出来**。⇒ 反过来说：**那一天里这个脚本本该抓到的错，只能靠我自己用眼睛读出来**。 |
| **可复用的纪律** | ① **检查器必须先自证**：断言「我定位到了正确对象」「我核到的格数够多」，并让**汇总数字来自计数变量**；② ⛔ **绝不无条件打印「0 项不符」**——**汇总行必须由 `mism` 生成**，因为「指标与明细能否对账」正是发现假 PASS 的唯一线索；③ **读输出要读到明细**：前面有 ⛔ 行、末行却说 0，这个**不对称**就是假 PASS 的指纹。 |
| **同族与相关** | [局部搜索不能支撑否定结论](../../局部搜索不能支撑否定结论/README.md) 的实测②（同一个动作：**加断言自证「数据真的读到了」**）｜[检查有效性必须被验证](../../检查有效性必须被验证.md)（**一个从不失败的检查，无法证明它有效**）｜[../诚实记录/已知假PASS的经历.md](../../../诚实记录/已知假PASS的经历.md)（本目录既有的假 PASS 留痕：**指标与明细必须能对账**） |
