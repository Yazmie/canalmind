**这一子主题讲什么**：**验证工具自己的生命周期**——它有两条对称的失效形态：
①**从没跑过**（那个诊断开关当天就写进文档、也被别的会话确认「代码里有」，却从没人见过它产出的文件——
**「已实现」不等于「已验证」，没产物就没证据**；它第一次真跑就推翻了一条已写进文档的结论）；
②**跑过、也拿到了数，然后脚本被删了**（⇒ 结论不可复查、改坏不变红、**下一轮从零重写时重踩已记录过的坑**）。
