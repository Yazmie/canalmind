## 顺带实测：这个开关自己的两条行为契约（⚠️ 本轮只实测了这两条）

| 契约 | 实测结果 |
|---|---|
| **语法非法的路径** | ✅ `参数错误：--dump-rerank 的路径非法：「…」（Illegal char …）`、**退出码 2**、耗时 **0.3 s**（**未调模型**）。 |
| **`--dump-rerank` + `--no-rerank`** | ⚠️ **不创建文件**，只打印一行「本档关闭重排、一次模型都不调 ⇒ 该文件本轮不会有内容」，**退出码 0** ⇒ ⛔ **不得写成「写不进去 ⇒ 退出码 1」**——那句只在**开启重排**时适用，本轮**未**实测。 |

> ⚠️ 这两条合起来才是重点：**「没有文件」至少有三种成因**（① 写不进去＝错误——文档声称退出码 **1**，⛔ **本轮未实测**；② 本档不重排＝**不是**错误，**退出码 0 ✓**；③ 语法非法的路径＝命令行错误，**退出码 2 ✓**）。
> ⛔ **见到「没有文件」不要一律当成失败**——与

## 🔴 同族：我第一次测这两条契约时，**测法本身就是错的**

我把命令末尾挂了 `Select-Object -First 4` ⇒ **提前掐断管道、把 Java 进程打死**，
于是我读到的「**退出码 -1**」**根本不是程序的退出码** ✗。
**改法**：**先把输出收进变量、再切片**；重测后这两条契约分别是 **0 与 0** ✓。

⇒ **可复用的纪律：测量退出码时，⛔ 不要在同一条管道里截断输出**——否则你测到的是**管道**的行为，不是**程序**的行为。
