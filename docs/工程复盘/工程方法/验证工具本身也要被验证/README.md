# 验证工具本身也要被验证（主题索引）

> 类别：[工程方法](../README.md) ｜ 返回总索引：[../../README.md](../../README.md)

**这一主题讲什么**：用来诊断问题的**探针、脚本、正则、审计器**，本身就是会出错的一环。
**探针给出"结论"之前，必须先证明探针自己是对的**——否则你不是在测量系统，而是在测量自己的工具。
本条按 `AGENTS.md` §8.3 的递归规则（单条超过约 40 行 ⇒ 就地新建**主题子目录**、拆成多条）拆开。

| [探针假结论与正确姿势](探针假结论与正确姿势.md) | 主题总纲：核心原则 + 实测例子 ①②③（探针的语义 / 输入 / 判定模型各错一次）+ 代价 / 正确姿势 / 业务含义 / 可能被追问 |
| [度量脚本也要自证](度量脚本也要自证.md) | 实测例子 ④：给指标脚本加 `--selftest`，用**手算的期望值**断言指标实现——判据独立于实现 |
