## 本类共同教训

**对"自己产出的结论"保持怀疑，是可靠性的一部分。**

- 检查结果（PASS）不是无需验证的前提——**校验器本身也是代码，也会有 bug**。
- "我没找到"是检索行为，"它不存在"是事实断言——**后者需要举证**。
- 信息写在哪个文件，决定了它**会不会被需要它的人看到**。
- **合法 ≠ 正确**：转义写错、"替换没匹配上"、"分割切不开"，都能编译、能跑、能绿。
  这类错误只能靠**对照实验 + 十六进制/码点级断言**抓出来，读源码是抓不到的。
- 用来诊断的工具（探针、脚本、正则）**必须先被诊断**。跨语言复核正则尤其危险。
- **"可复现"包括字节可复现**：换行、编码、locale、时区这些"平台默认值"必须在产物里钉死，
  否则"这次差异"到底来自代码还是来自环境，永远说不清。
