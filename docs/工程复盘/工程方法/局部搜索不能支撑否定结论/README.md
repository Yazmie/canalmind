# 局部搜索不能支撑否定结论

> 类别：[工程方法](../README.md) ｜ 返回总索引：[../../README.md](../../README.md)

本主题子目录按 `AGENTS.md` §8.3 的递归规则，从原条目《局部搜索不能支撑否定结论》拆出。
它的核心命题是**一句话**里那条：**否定结论（「没有 / 不存在 / 未修 / 0 处差异」）比肯定结论需要更强的举证**。
下面每条各自解决其中一个子问题。

| 条目 | 它解决什么子问题 |
|---|---|
| [否定结论的举证标准与检查清单](否定结论的举证标准与检查清单.md) | 本主题的纲：四例的共同结构、纪律、被追问时怎么答、「空结果」的三种成因归纳与 8 条检查清单 |
| [字面量搜索与字段读错的假结论](字面量搜索与字段读错的假结论.md) | 工具给出了**看起来正常**的输出（搜索命中 3 处 / 「变好 0 变差 0 不变 40」），而我把它当成了事实 |
| [搜索范围不全支撑不了不存在](搜索范围不全支撑不了不存在.md) | 「我搜了没找到」≠「不存在」：只搜一个目录的代价，以及「全仓搜索」这句话本身可能是假的（含勘误留痕） |
| [空结果可能是查询被拒绝](空结果可能是查询被拒绝.md) | 「空 / 无」可能是**查询失败被静默**，不是「真的没有」；换一条独立路径复核，以及一条可复用的环境事实 |
