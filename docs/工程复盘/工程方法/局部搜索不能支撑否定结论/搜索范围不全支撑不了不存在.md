### ⚠️ 同一个坑的第二层：**「全仓搜索」这句话本身也可能是假的**

本条的写作过程里复现了这条：用**默认的 ripgrep 语义**搜 `16384`，命中 24 处，
**全部落在 `docs/` 与 `backend/src/` 这些非忽略路径下**；而**同样含该串的** `backend/target/eval/v2_datapack.md`
（被 `.gitignore` 排除）**根本不在结果里**。
⇒ **若你的搜索工具默认跳过 `.gitignore`，那么「我全仓搜过了」就是一句假话，而它读起来像真的。**
所以「搜索范围」必须**逐字写进结论**：搜了哪些目录、含不含被忽略与构建目录、**用的哪个 cmdlet 与哪个参数**。

**覆盖被忽略路径的正确写法（逐个 cmdlet 核过，本机实测）**：⚠️ **开关不一样，别混用**——

| 写法 | 能不能覆盖被忽略路径 | 实测 |
|---|---|---|
| `Get-ChildItem -Recurse` **`-Force`** | ✅ 它**有** `-Force`（用来列出隐藏 / 被忽略的**文件**） | `Get-ChildItem <…>\backend\target\eval -Recurse -Force -File -Filter *.md` → 列出 `v2_datapack.md` 等 **4 个**文件 |
| `Select-String -Path <具体路径> -Pattern <串>` | ✅ **直接给路径就能读到**被忽略的文件；⛔ **它没有、也不能加 `-Force`** | `Select-String -Path <…>\v2_datapack.md -Pattern 16384` → 命中 **4 行**（首行号 298）；加 `-Force` 则报 `A parameter cannot be found that matches parameter name 'Force'.` |
| Python `pathlib.Path(...).read_text(...)` | ✅ 不看 `.gitignore` | 读到 **23863 字符**、含 `16384` ✓ |

⚠️ **勘误留痕（同一个坑的第三层，不许静默改掉）**：本节初稿写的是「换成含 `-Force` 的 `Select-String` 才把它找出来」——
**这句话是假的**：`Select-String` **没有** `-Force` 参数（本机实测报
`A parameter cannot be found that matches parameter name 'Force'.`）。
真因是我把 **`Get-ChildItem -Force`** 与 **`Select-String`** **混为一谈**：`-Force` 属于前者，**不属于后者**。
⇒ 教训：**引用命令时必须把「cmdlet ＋ 参数」当成一个整体去核，⛔ 不能只核「我加了某个开关」**——
这正是「**结论的锚点必须能被别人逐字复跑**」的具体形态：**开关名对了、却挂错了命令，命令照样跑不起来。**
