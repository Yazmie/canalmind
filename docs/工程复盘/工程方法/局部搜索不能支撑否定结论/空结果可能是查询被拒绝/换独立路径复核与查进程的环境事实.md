**换一条独立路径确认**（CIM 与 .NET 进程 API 是两套不同实现）：

```powershell
Get-Process java
# → PID 15760 启动 10:51:10，CPU ≈ 10.8 s / 工作集 ≈ 346 MB（正是我的批次）
```

> ⚠️ **两条命令给出相反的答案，而只有一条是真的**：一条说「没有」，一条说「有一个约 346 MB 的 JVM 正在跑」。
> **工具说「没有」时，先怀疑工具**——这与本目录既有的 [验证工具本身也要被验证](../../验证工具本身也要被验证/README.md)
> 是同一条：**「没有」是一个结论，不是一个观测。**

### ⚠️ 顺带一条可复用的环境事实（本机实测）

- **受限环境下 `Get-CimInstance Win32_Process` 会被拒绝访问**（异常消息就是「拒绝访问」），
  而这个失败**默认可被 `-ErrorAction SilentlyContinue` 静默成空结果**；
- 查进程请用 **`Get-Process`**（实测可用，能给出 PID / 启动时间 / CPU / 工作集）；
- 且**不要**用 `SilentlyContinue` 掩盖它的失败——要么 `-ErrorAction Stop` + `try/catch` 打印，
  要么就让错误冒出来。
