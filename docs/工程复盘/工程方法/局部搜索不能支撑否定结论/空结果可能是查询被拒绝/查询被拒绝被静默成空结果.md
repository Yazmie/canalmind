## 实测 ④：空结果可能是「查询被拒绝」，不是「没有」

我为确认「**是否还有并发付费长跑在抢资源**」而查进程——当时的写法（注意 `-ErrorAction SilentlyContinue`）：

```powershell
$js = Get-CimInstance Win32_Process -Filter "Name='java.exe'" -ErrorAction SilentlyContinue
if ($js) { … } else { "（无 java 进程）" }
```

输出：**「（无 java 进程）」** ⛔ —— 而**我自己**的付费批次**当时正在跑**。

去掉静默之后，同一个查询的真实结果：

```powershell
try { Get-CimInstance Win32_Process -Filter "Name='java.exe'" -ErrorAction Stop }
catch { $_.Exception.Message }
# → 拒绝访问
```

⇒ **`Get-CimInstance` 在受限环境被拒绝访问**；`-ErrorAction SilentlyContinue` 把异常**吞掉**，
于是**「查询本身失败」变成了一个看起来干净的「空结果」**，而我又把空结果读成了**否定结论** ✗。
**这两种输出长得一模一样**：代码走的是同一个 `else` 分支，读的人看到的都是那句「（无 …）」。
