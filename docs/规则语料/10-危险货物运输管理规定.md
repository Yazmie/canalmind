# 危险货物运输管理规定

## 第一章 总则

### 第一条 【目的与依据】

为规范平陆运河危险货物的运输、过闸与作业管理，明确危险货物的认定分类、船舶实体条件、隔离要求与专用闸次安排，防范运输过程中的火灾、爆炸、泄漏与污染事故，保障航道、船闸与港口设施安全，制定本规定。本规定为平陆运河危险货物运输管理的专项规范；危险货物的术语含义按《术语与定义》（PLYH-GZ-2026-025）关于危险货物的定义认定；危险货物的费用计收口径按《计费总则》（PLYH-GZ-2026-005）关于危险货物计费的规定执行。

### 第二条 【适用范围】

本规定适用于在平陆运河航道及其沿线港口、船闸、锚地范围内发生的危险货物运输活动：

1. 危险货物的船舶载运与过闸；
2. 危险货物在港区的装卸、堆存与交接；
3. 危险货物运输船舶的停泊、待闸与应急处置。

危险货物的申报材料编制、受理与审核流程，不在本规定中规定，按危险货物申报与审核的专项细则执行。

### 第三条 【管理原则】

危险货物运输管理遵循下列原则：

1. **分类管理原则**。危险货物按其危险特性分类，不同类别的船舶条件、隔离要求与作业限制不同。
2. **专闸专段原则**。危险货物应当使用专用闸次通过船闸，不得与普通货类无条件混放。
3. **先报后运原则**。危险货物运输须先完成申报并取得审核通过，方可安排装船与过闸。
4. **全程可溯原则**。危险货物自装船至卸船的类别、数量、包装与承运船舶应当全程记录、可追溯。

## 第二章 分类与货类归属
### 第四条 【危险货物定义】

危险货物是指具有爆炸、易燃、毒害、感染、腐蚀、放射性等危险特性，在运输、装卸、堆存过程中容易造成人身伤亡、财产损毁或者环境污染，因而需要特别防护的货物。

危险货物的认定，按《术语与定义》（PLYH-GZ-2026-025）关于危险货物的定义执行。该定义与本规定不一致的，以《术语与定义》（PLYH-GZ-2026-025）为准。

### 第五条 【危险特性分类】

危险货物按其主要危险特性分为下列六类：

| 危险特性类别 | 类别代号 | 主要货种举例 |
|---|---|---|
| 爆炸品 | 一类 | 工业雷管、硝化甘油制品 |
| 压缩与液化气体 | 二类 | 液化天然气、液化石油气、工业氧气 |
| 易燃液体 | 三类 | 汽油、燃料油、甲醇、涂料溶剂 |
| 易燃固体与自燃物质 | 四类 | 硫磺、石油焦、电石 |
| 氧化剂与有机过氧化物 | 五类 | 过氧化氢、硝酸铵 |
| 毒害与腐蚀性物质 | 六类 | 农药原药、硫酸、烧碱、基础化工原料 |

⚠️ 上表六类为**按危险特性的完整枚举**，仅用于安全管理的分类，**不是货类大类**。

### 第六条 【危险货物与计费货类的对应】

危险货物**不是独立的货类大类**。危险货物在计费与统计时，一律按其**物理化学性质**归入《计费总则》（PLYH-GZ-2026-005）确定的七个货类大类之一：

| 危险特性类别 | 对应货类大类 | 说明 |
|---|---|---|
| 一类 爆炸品 | 化工 | 工业爆破器材按化工类归集 |
| 二类 压缩与液化气体 | 能源 | 液化天然气、液化石油气按能源类归集 |
| 三类 易燃液体 | 能源 | 燃料油按能源类归集；甲醇等基础化工原料按化工类归集 |
| 四类 易燃固体与自燃物质 | 能源 | 石油焦按能源类归集；硫磺按化工类归集 |
| 五类 氧化剂与有机过氧化物 | 化工 | 硝酸铵、过氧化氢按化工类归集 |
| 六类 毒害与腐蚀性物质 | 化工 | 硫酸、烧碱、农药原药按化工类归集 |

危险货物对应的货类大类仅为**建材、能源、金属、农资、化工、集装箱、其他**七个之一。承托双方不得以"危险品""危货"等名称作为货类大类申报或者计费；申报单证中出现此类名称的，按本条规定归入对应货类大类后计费。

### 第七条 【货类归属争议的认定】

危险货物的货类大类归属存在争议时，按下列顺序认定：

1. 以运输单证载明的货物名称及其理化性质说明为准；
2. 单证载明不明确的，以《安全技术说明书》载明的危险特性为准；
3. 仍无法认定的，由平陆运河航运服务中心业务部门会同海事管理机构核定，并书面告知托运人。

## 第三章 船舶与实体条件

### 第八条 【承运船舶条件】

载运危险货物的船舶应当同时具备下列条件：

1. 持有有效的**危险货物适装证明**，适装证明载明的适装类别应当覆盖本次载运的货物；
2. 船舶检验证书在有效期内，且检验结论载明适于载运危险货物；
3. 按规定配备消防、堵漏、防爆、呼吸保护与洗消设备；
4. 船舶自动识别系统（AIS）全程开启并正常工作；
5. 船舶近十二个月内未发生负主要责任的危险货物污染或者泄漏事故。

### 第九条 【适装证明有效期】

1. 危险货物适装证明的有效期**不超过二十四个月**。
2. 适装证明有效期届满前**三十日**内，船舶所有人应当申请换发。
3. 适装证明失效、被撤销或者被暂扣期间，船舶不得载运危险货物；已装船的，应当在指定锚地卸载或者转驳。
4. 船舶结构、货舱涂层或者货物管系发生实质性改动的，原适装证明自改动之日起失效，应当重新申请检验。

### 第十条 【船员与作业人员条件】

1. 载运危险货物的船舶，船长与负责货物操作的船员应当经过危险货物运输专业培训，并持有相应的培训合格证明。
2. 船上应当至少配备**两名**经过危险货物应急处置培训的船员。
3. 危险货物装卸作业期间，船上值班人员不得少于**两人**，且不得同时兼任装卸指挥以外的其他作业；装卸作业人员应当接受作业前的安全交底，交底记录随船留存不少于**六个月**。

### 第十一条 【载运量与配载限制】

1. 单船载运危险货物的总量**不得超过**船舶适装证明核定的最大载运量。
2. 不同危险特性类别的危险货物，除按本章规定的隔离要求可以同舱或者相邻舱配载外，应当分舱配载。
3. 危险货物不得与食品、粮食、饲料等直接入口或者饲用货物、鲜活货物、旅客行李与生活用品同舱配载。
4. 危险货物与食品、粮食、饲料、鲜活货物、旅客行李及生活用品的舱位隔离，应当满足**至少一个空舱或者一道隔离舱壁**的要求。

### 第十二条 【标志与标识】

1. 载运危险货物的船舶应当在船体两舷及船首显著位置显示所载危险特性的标志或者标牌。
2. 危险货物包装件应当标明货物名称、危险特性类别、净重与应急联系信息。
3. 夜间航行或者作业时，标志应当具备反光或者照明功能，保证**二百米**外可辨识。
4. 标志脱落、污损不可辨识的，应当在装船前更换；未更换的不得装船。

### 第十三条 【申报与实体条件的衔接】

1. 危险货物运输的申报要求按危险货物申报与审核的专项细则执行。
2. 申报经审核通过，仅表明申报材料齐备、形式合规，**不替代**本章规定的船舶与实体条件。
3. 船闸调度机构在编排闸次前，应当核验承运船舶的适装证明与本章规定的设备配备情况；核验不通过的，不得编排危险货物专用闸次。
4. 已通过审核但现场核验不通过的，按未通过申报处理，并按危险货物申报与审核的专项细则关于驳回的规定办理。

## 第四章 专用闸次与隔离

### 第十四条 【专用闸次安排】

1. 危险货物应当使用**危险货物专用闸次**通过船闸。
2. 专用闸次每日安排**四个**，分别为 02:00、08:00、14:00、20:00 起放行，每个闸次的作业时长不超过**九十分钟**。
3. 危险货物专用闸次与相邻的普通货类闸次之间，应当留有**不少于六十分钟**的安全间隔。
4. 同一专用闸次内仅放行**一个**危险货物船舶编队，编队船舶数量不超过**四艘**。
5. 当日危险货物申报量超过专用闸次通过能力的，超出部分的船舶在指定锚地待闸，顺延至次一专用闸次放行。

### 第十五条 【分批放行要求】

1. 危险货物与普通货类**分批放行**，不得在同一闸次、同一充水周期内混合通过。
2. 危险货物专用闸次与普通货类闸次之间应当**清空闸室**，确认无残留船舶及漂浮物后方可组织下一批次的船舶进闸。
3. 前一闸次为危险货物专用闸次的，后一普通货类闸次的船舶进闸时间应当在上一次放行完成后**不少于六十分钟**。
4. 因抢修、抢险等紧急情形需要打破分批放行要求的，应当经平陆运河航运服务中心负责人批准，并在航行通告中公告。

### 第十六条 【间距与隔离要求】

1. 同一专用闸次编队内的船舶，船与船之间的纵向净距不得少于**五十米**。
2. 危险货物专用闸次放行期间，船闸上下游引航道**一千米**范围内不得有其他船舶锚泊、装卸或者从事明火作业。
3. 载运危险货物**三百吨以上**的船舶，不得与本闸次内载运食品、粮食、鲜活货物的船舶相邻靠泊待闸。
4. 危险货物船舶在待闸锚地应当单船单锚位停泊，锚位间距不得少于**一百米**。

### 第十七条 【气象与水文条件限制】

出现下列情形之一的，暂停危险货物专用闸次的放行：

1. 阵风风力达到**七级**以上；
2. 能见度不足**一千米**；
3. 航道发布洪水、暴雨或者雷电红色预警；
4. 船闸设备处于检修状态或者故障处置期间。

暂停情形消失后，由船闸调度机构重新编排专用闸次，并优先放行已在待闸锚地等候的船舶。

## 第五章 费用、记录与应急

### 第十八条 【费用计收依据】

1. 危险货物的费用按其对应的货类大类，依据《计费总则》（PLYH-GZ-2026-005）确定的费种与计费口径计收。
2. 危险货物的过闸费，在对应货类费率基础上**加收百分之三十**，作为危险货物作业附加费。
3. 附加费**不单独设立费率条目**，其计算基数为对应货类、对应吨位段适用的费率。
4. 危险货物不得因其危险特性而改变货类大类的归属，亦不得据此适用其他货类的费率。

### 第十九条 【记录与留存】

#### 一、运输记录的内容

1. 承运人应当建立危险货物运输记录，载明货物名称、危险特性类别、对应货类大类、数量、包装、承运船舶与过闸闸次；记录中的货类大类应当按本规定第六条填写，不得填写"危险品"等非大类名称。
2. 危险货物运输记录自卸货完成之日起留存不少于**二十四个月**。

#### 二、闸次记录与更正

1. 危险货物通过专用闸次时，船闸调度机构应当单独记录闸次时刻、编队组成与间隔时间，留存不少于**十二个月**。
2. 记录内容不得涂改；确需更正的，应当保留原始记录并注明更正原因与更正人。

### 第二十条 【应急处置】

1. 载运危险货物的船舶发生泄漏、起火、爆炸或者人员中毒的，应当立即向船闸调度机构与海事管理机构报告。
2. 报告内容应当包括船位、货物名称、危险特性类别、数量、已采取的措施与需要的支援。
3. 船闸调度机构接到报告后，应当立即暂停相邻闸次作业，划定安全区域，并通知下游船舶避让。
4. 应急处置结束后，船舶应当提交事故情况报告；未提交的，其后续危险货物运输申报不予受理。

本规定由平陆运河航运服务中心负责解释，自 2026 年 9 月 16 日起施行。
