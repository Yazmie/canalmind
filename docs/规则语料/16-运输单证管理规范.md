# 运输单证管理规范

## 第一章 总则

### 第一条 【目的与依据】

为规范平陆运河货物运输单证的种类、记载事项、签发、流转与归档管理，明确运单与提单的区别与适用情形，保证运输业务可追溯、可复核，制定本规范。

### 第二条 【适用范围】

本规范适用于在平陆运河航道及其沿线港口、船闸、锚地范围内办理的下列运输业务的单证管理：

1. 经平陆运河的货物运输业务；
2. 过闸申报业务；
3. 货物在港区的装卸与交接业务；
4. 与上述业务相关的费用结算业务。

### 第三条 【单证管理职责】

1. 平陆运河航运服务中心（以下称"航运服务中心"）负责单证格式的规范、单证信息的记录与归档情况的核查。
2. 承运人负责单证的填制、签认、交付与归档，并对单证记载内容的真实性负责。
3. 托运人负责提供真实的货物信息；港口经营人负责装卸作业单与货物交接单的填制与签认。

## 第二章 单证种类与记载事项

### 第四条 【单证种类】

运输业务涉及的运输单证种类如下：

| 单证种类 | 填制主体 | 适用环节 | 是否随船 |
|---|---|---|---|
| 水路货物运单 | 托运人填制，承运人签认 | 非集装箱货物运输 | 是 |
| 水路货物提单 | 承运人签发 | 需要凭单提货的货物运输 | 是（副本） |
| 过闸申报单 | 船舶所有人、经营人 | 过闸申报 | 否 |
| 装卸作业单 | 港口经营人 | 装卸作业 | 否 |
| 货物交接单 | 承运人与港口经营人 | 货物交接 | 否 |
| 危险货物运输申报单 | 托运人或者申报主体 | 危险货物运输申报 | 是 |
| 费用结算单 | 航运服务中心、港口经营人 | 费用结算 | 否 |

上表所列单证种类为完整枚举。业务办理不得以"随货同行单""放货条"等非本规范列举的单据替代上述单证。

### 第五条 【运单的记载事项】

水路货物运单应当载明下列事项：

1. 运单编号与签发日期；
2. 托运人、收货人名称与联系方式；
3. 承运人名称、船舶名称与船舶识别号；
4. 起运港、到达港；
5. 货物名称、货类大类、件数、重量（吨位）；
6. 集装箱货物应当载明箱号与箱量；
7. 运费及其支付方式；
8. 托运人与承运人签认。

前款第五项载明的货类大类，应当为**建材、能源、金属、农资、化工、集装箱、其他**七个大类之一，不得以"危险品""散货""杂货"等名称替代。

### 第六条 【提单的记载事项】

水路货物提单应当载明下列事项：

1. 提单编号、签发日期与签发地点；
2. 托运人、收货人名称；指示提单应当载明"凭指示"字样；
3. 承运人名称、船舶名称与船舶识别号；
4. 起运港、到达港；
5. 货物名称、货类大类、件数、重量（吨位）、集装箱箱号；
6. 运费及其支付方式；
7. 提单正本的份数；
8. 承运人签章。

提单应当载明"凭本提单正本提货"字样。收货人未提交提单正本的，承运人、港口经营人不得交付货物。

### 第七条 【单证的编号与货物名称填写】

1. 各类单证应当按航次编定唯一编号，编号应当包含年份、航次序号两项要素。
2. 单证载明的货物名称应当与危险货物运输申报单、货物交接单载明的名称一致。
3. 同一批货物跨多个航段运输的，各航段单证编号应当相互关联，以便追溯全程运输。
4. 货物名称填写不明确的，按《计费总则》（PLYH-GZ-2026-005）关于货类认定争议的规定确定货类大类。

## 第三章 运单与提单的区别与适用

### 第八条 【运单与提单的区别】

运单与提单的区别如下：

| 比较项 | 水路货物运单 | 水路货物提单 |
|---|---|---|
| 法律性质 | 运输合同与货物收据 | 货物收据与提货凭证 |
| 提货方式 | 收货人凭身份证明提货 | 收货人凭提单正本提货 |
| 可否转让 | 不得转让 | 记名提单不得转让；指示提单经背书转让 |
| 签发份数 | 一式 **3** 份（托运人、承运人、收货人各 1 份） | 正本一式 **3** 份，副本份数按需要确定 |
| 适用货物 | 大宗散货、非集装箱货物 | 集装箱货物、需要凭单提货的货物 |
| 归档保存期限 | **3 年** | **5 年** |

### 第九条 【运单的适用情形】

有下列情形之一的，应当使用水路货物运单：

1. 运输建材、能源、金属、农资、化工类的散装或者件杂货物；
2. 收货人已确定，无需凭单提货的；
3. 不需要以提单办理结算的；
4. 同一托运人、同一收货人、同一货类大类的连续批量运输。

### 第十条 【提单的适用情形】

有下列情形之一的，应当使用水路货物提单：

1. 运输集装箱货物；
2. 托运人要求凭单提货的；
3. 以信用证方式结算，需要提交提单办理结汇的；
4. 货物在运输途中需要转让或者以提单设定担保的。

### 第十一条 【运单与提单的转换与并用】

1. 同一批货物不得同时以运单与提单作为提货凭证。
2. 已签发运单、需要改用提单的，应当收回原运单并注明"作废，改签提单"，作废的运单仍应当归档。
3. 已签发提单、需要改用运单的，应当收回全部提单正本后方可签发运单；提单正本未能全部收回的，不得改签。

### 第十二条 【电子单证】

1. 本规范所列单证可以电子形式出具，电子单证与纸质单证具有同等效力。
2. 电子单证应当具备可核验的签发时间与签认信息。
3. 电子单证与纸质单证并存的，记载内容应当一致；不一致的，以经承运人签认的电子单证为准。

## 第四章 单证流转、更正与归档

### 第十三条 【单证的签发与签认】

1. 承运人应当在接收货物完成后签发运单或者提单，签发的份数按第八条的规定确定。
2. 单证签认应当包括签认主体名称、签认人姓名与签认日期，不得仅以印章替代签认日期。
3. 单证记载内容与实际货物不符的，承运人可以要求托运人更正后签发；托运人拒不更正的，承运人应当在单证上注明实际情况。

### 第十四条 【单证的流转】

单证的流转按下列顺序办理：

1. 托运人填制运单或者向承运人提交订舱信息；
2. 承运人签认并在货物装船后交付单证；
3. 载货船舶随船携带运单或者提单副本；
4. 船舶到达港后，承运人与港口经营人办理货物交接并签认货物交接单；
5. 收货人凭运单和身份证明，或者凭提单正本办理提货；
6. 业务完成后，由承运人按航次归集全部单证并归档。

承运人应当在货物交付完成之日起 **24 小时**内完成单证归集；过闸申报单应当与对应航次的运单或者提单关联归档。

### 第十五条 【单证的更正】

1. 单证记载内容不得涂改。确需更正的，应当在更正处加盖更正章，并由原签认双方签认并注明更正日期。
2. 涉及货物件数、重量（吨位）、货类大类的更正，应当重新核定后办理，并留存核定依据。
3. 单证更正后，原记载内容应当保持可辨识，不得覆盖或者销毁。
4. 涉及费用结算的更正，按费用差错更正的专项规定另行处理。

### 第十六条 【归档要求】

1. 单证归档应当以航次为单位，按航运服务中心统一的目录结构存放。
2. 归档时应当核对单证种类是否齐全；缺少装卸作业单或者货物交接单的，应当查明原因并补充说明材料。
3. 电子单证与纸质单证应当对应归档，电子单证的存储介质应当定期备份。
4. 归档后的单证不得擅自抽换、修改。

### 第十七条 【归档保存期限】

各类单证的最短归档保存期限如下：

| 单证种类 | 最短保存期限 |
|---|---|
| 水路货物运单 | **3 年** |
| 水路货物提单 | **5 年** |
| 过闸申报单 | **3 年** |
| 装卸作业单 | **2 年** |
| 货物交接单 | **3 年** |
| 危险货物运输申报单 | **5 年** |
| 费用结算单与费用明细 | **10 年** |

1. 保存期限自该航次结束之日起计算。
2. 涉及费用争议、货损货差争议尚未处理完毕的，相关单证应当保存至争议处理完毕后再保存 **3 年**。
3. 保存期限届满需要销毁的，应当编制销毁清单，销毁清单留存 **3 年**备查。
4. 单证记载事项与归档情况应当可供查询与复核。
