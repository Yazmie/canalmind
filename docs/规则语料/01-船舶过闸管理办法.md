# 船舶过闸管理办法

## 第一章 总则

### 第一条 【目的与依据】

为规范平陆运河船舶过闸的申请、预约、闸次编排与现场作业管理，维护通航秩序，保障船闸运行安全和船舶通行效率，制定本办法。

本办法是平陆运河船舶过闸管理的基本规范。过闸申报的时限、材料与调度排序，按《过闸申报与调度规程》（PLYH-GZ-2026-002）执行；船舶尺度与吃水限值，按《船舶尺度与吃水控制标准》（PLYH-GZ-2026-003）执行；重点物资的优先过闸，按《重点物资优先过闸规定》（PLYH-GZ-2026-004）执行。

### 第二条 【适用范围】

本办法适用于在马道枢纽船闸、企石枢纽船闸、青年枢纽船闸过闸的下列船舶：

1. 干散货船；
2. 集装箱船；
3. 多用途船；
4. 化学品船；
5. 驳船。

军事船舶、公务船舶以及依法免于缴费的船舶过闸，不适用本办法，按国家有关规定执行。

### 第三条 【职责分工】

1. 航运服务中心负责过闸申请的受理、闸次编排、调度指令的发布以及过闸业务的监督管理。
2. 船闸运行单位负责闸室设备操作、现场安全管理和过闸作业的组织实施。
3. 船舶所有人、经营人或者其代理人负责如实申报过闸信息，并按调度指令组织过闸。
4. 船舶应当服从现场调度指挥；对调度指令有异议的，可以在过闸完成后的 3 个工作日内提出复核申请，但不得拒绝执行。

### 第四条 【过闸方式与作业时段】

1. 平陆运河三大梯级枢纽即马道枢纽、企石枢纽、青年枢纽，各设**双线船闸**，全运河共 **6 个闸室**，闸室编号为 1 号与 2 号。双线船闸的含义按《术语与定义》（PLYH-GZ-2026-025）确定。
2. 船闸实行 **24 小时**通航，闸次按调度计划连续编排。
3. 船舶过闸实行"**一次申报、一次编排、依次过闸**"：同一船舶在同一航次内通过多个枢纽船闸的，应当一次性完成申报，由调度机构统一编排各枢纽的闸次。
4. 因检修、水位或者气象原因需要停止通航的，船闸运行单位应当提前 **24 小时**发布通告；紧急情况下可以即时发布。

## 第二章 过闸申请与预约

### 第五条 【申请条件】

船舶申请过闸，应当同时具备下列条件：

1. 船舶已在业务系统中完成登记，船舶登记标识、船型、载重吨、吃水等信息真实有效；
2. 船舶尺度符合《船舶尺度与吃水控制标准》（PLYH-GZ-2026-003）规定的限值；
3. 已在《过闸申报与调度规程》（PLYH-GZ-2026-002）规定的申报时限内完成过闸申报；
4. 载运危险货物的船舶，已按规定完成危险货物申报与审核；
5. 按规定应当缴纳过闸费的，已完成费用确认或者提供有效担保。

不符合前款任一条件的，不予编排闸次。

### 第六条 【申请方式与受理时限】

#### 一、申请方式

1. 船舶所有人、经营人或者其代理人通过航运服务中心业务系统提交过闸申请；
2. 因系统故障等特殊原因无法在线提交的，可以书面方式向船闸调度机构提交，并在系统恢复后的 24 小时内补录。

#### 二、受理时限

1. 航运服务中心应当在收到过闸申请后的 **2 小时**内完成形式审查，作出受理或者不予受理的决定；
2. 不予受理的，应当一次性告知需要补正的全部内容；
3. 申请材料补正后重新提交的，受理时限自重新提交之时重新计算。

### 第七条 【预约与预约号】

1. 过闸申请受理后，由业务系统生成过闸预约号，作为船舶预约过闸的凭证。
2. 预约号载明枢纽船闸标识、编排日期与顺序号，实行一船一航次一号。
3. 预约号的保留时限为 **6 小时**；船舶未在保留时限内进闸的，预约号失效，应当重新申请。
4. 船舶不得转让、倒卖预约号。违反规定的，自认定之日起 **30 日**内不予受理其新的过闸申请。

### 第八条 【申请信息的更正】

1. 船舶在进闸前发现申报信息有误的，应当在**进闸前 2 小时**申请更正。
2. 更正内容涉及船舶总长、船宽、吃水或者货类的，重新按更正后的信息进行尺度核验与费用确认。
3. 进闸后不得再申请更正申报信息；确因申报错误造成闸次编排损失的，按过错责任承担相应费用。

## 第三章 闸次编排与优先放行

### 第九条 【闸次编排原则】

闸次编排遵循下列原则：

1. **安全优先**。编入同一闸次的船舶之间、船舶与闸室边界之间应当保持规定的安全间距；
2. **顺序优先**。在满足安全条件的前提下，按完成申报的时点先后安排闸次；
3. **集约高效**。同一闸次宜编入尺度相近、航向相同的船舶，提高闸室利用率；
4. **航次衔接**。同一船舶在同一航次内通过多个枢纽船闸的，各枢纽闸次应当相互衔接，衔接等待时间原则上不超过 **4 小时**。

### 第十条 【单闸次编组规则】

单个闸次编入船舶应当符合下列编组规则：

| 编组要素 | 规定 |
|---|---|
| 单闸次最大船舶数 | 不超过 4 艘 |
| 同一闸次船舶航向 | 相同 |
| 船舶之间纵向间距 | 不少于 5 米 |
| 船舶与闸室端部间距 | 不少于 10 米 |
| 并列船舶宽度之和 | 不超过 30 米 |
| 相邻闸次编排间隔 | 不少于 45 分钟 |

1. 上表为一般规定。船舶尺度与吃水的具体限值，按《船舶尺度与吃水控制标准》（PLYH-GZ-2026-003）执行，本办法不作规定。
2. 危险货物专用闸次、超限专用闸次的编队数量、闸次间隔与船间净距，从其专项规定；专项规定严于上表的，从严执行。

### 第十一条 【优先放行的情形】

下列情形可以优先放行：

1. 执行防汛、抢险、救灾等紧急任务的船舶；
2. 载运重点保供物资并按规定取得优先资格的船舶；
3. 已在申报时限内完成申报且处于待闸状态的船舶，相对未完成申报的船舶优先安排。

本条第 2 项优先资格的取得条件、优先等级与适用顺序，按《重点物资优先过闸规定》（PLYH-GZ-2026-004）执行；本条第 3 项的排序规则，按《过闸申报与调度规程》（PLYH-GZ-2026-002）执行。

### 第十二条 【优先放行的实施】

1. 优先放行不改变本办法关于尺度核验、安全间距与危险货物作业的要求。
2. 优先放行不免除过闸费的缴纳义务，也不减免任何费用。
3. 同一闸次内存在多艘具备优先资格的船舶时，按优先等级由高到低安排；等级相同的，按完成申报的时点先后安排。
4. 因优先放行导致其他船舶顺位后移的，调度机构应当发布闸次调整通知。

## 第四章 过闸作业与现场管理

### 第十三条 【进闸前准备】

1. 船舶应当在调度指令指定的时间前 **30 分钟**到达指定待闸区；
2. 进闸前应当完成主机、舵机、锚机及系缆设备的检查，确保设备状态正常；
3. 船舶应当保持甚高频通信设备守听，并听从现场调度指挥。

### 第十四条 【闸室内作业规范】

1. 船舶进闸速度不超过 **0.5 米/秒**，闸室内禁止追越、并靠和掉头；
2. 船舶应当系妥缆绳，系缆后主机置于随时可用状态；
3. 闸门关闭后，船上人员不得在甲板边缘作业；
4. 闸室充泄水期间，船舶应当持续观察缆绳受力情况，发现异常立即报告。

### 第十五条 【过闸费的收取口径】

1. 过闸费**仅对经平陆运河的航次收取**。航次起点港或者终点港属于运河节点港的，认定为经平陆运河的航次。
2. 运河节点港由航运服务中心公布并在业务系统中标记，现行运河节点港如下：

| 港区名称 | 江段 | 类型 | 运河节点 |
|---|---|---|---|
| 平塘江口港点 | 平陆运河 | 枢纽 | 是 |
| 陆屋港 | 平陆运河 | 枢纽 | 是 |
| 钦州内河港 | 钦江 | 内河港 | 是 |
| 钦州港 | 沿海 | 海港 | 是 |
| 钦州港保税港区 | 沿海 | 海港 | 是 |

3. 起点港与终点港均非运河节点港的航次，不属于经平陆运河的航次，不收取过闸费。
4. 空载航次不计收过闸费；过闸费的计费单位与费率按现行过闸费费率表执行。
5. 港口节点标记调整后，自调整之日起适用于当日及以后发生的航次，不追溯调整已结算费用。

### 第十六条 【过闸记录与档案】

1. 每个闸次应当形成闸次记录，载明枢纽船闸名称、闸室编号、过闸日期与时间、船舶清单及载货吨位；
2. 闸次记录保存期限不少于 **3 年**；
3. 船舶可以查询本船过闸记录；对记录内容有异议的，按费用争议处理的专项规定办理。

### 第十七条 【违规情形的处理】

1. 未按调度指令进闸、抢档进闸或者擅自滞留闸室的，责令改正，并可暂停其预约资格 **7 日**；
2. 转让、倒卖预约号的，按本办法第七条第 4 项处理；
3. 拒不服从现场调度指挥，情节严重的，移交海事管理机构依法处理。
