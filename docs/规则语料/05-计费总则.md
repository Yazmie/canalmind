# 计费总则

## 第一章 总则

### 第一条 【目的与依据】

为规范平陆运河航运物流业务的费用计算与收取，明确各费种的适用范围、计费单位与计费口径，保障托运人、承运人与服务提供方的合法权益，制定本总则。

本总则为平陆运河航运物流计费的基础性规范。各专项费率表（过闸费、引航费、停泊费、港杂费、装卸费）所载具体费率，均以本总则确定的费种名称、货类划分与计费口径为准。

### 第二条 【适用范围】

本总则适用于在平陆运河航道及其沿线港口、船闸、锚地范围内发生的下列业务：

1. 船舶过闸业务；
2. 船舶引航业务；
3. 船舶停泊与靠离泊辅助业务；
4. 货物在港区的港杂与装卸业务。

军事船舶、公务船舶以及依法享受费用减免的船舶，其计费不适用本总则，按国家有关规定执行。

### 第三条 【计费原则】

费用计算遵循下列原则：

1. **据实计费原则**。费用应按实际发生的业务量、实际适用的费率标准计算，不得预估收费或者事后追补费率差额。
2. **时点适用原则**。费率按业务发生日的费率标准执行，不按合同签订日、申报日或结算日执行。
3. **单一适用原则**。同一业务、同一费种、同一吨位段在任一时点最多适用一条费率规则，不得重复计费。
4. **公开透明原则**。各费种费率与计费口径应当公开，费用明细应当可查询、可复核。

## 第二章 费种与计费口径

### 第四条 【费种构成】

平陆运河航运物流业务费用由下列五个费种构成：

| 费种 | 计费单位 | 计费对象 | 说明 |
|---|---|---|---|
| 过闸费 | 元/吨 | 经船闸的船舶载货吨位 | 仅对经平陆运河的航次收取 |
| 引航费 | 元/次 | 引航服务次数 | 按船舶总吨位分段计价 |
| 停泊费 | 元/吨天 | 停泊吨位与停泊天数 | 不足一日按一日计 |
| 港杂费 | 元/次 | 货物进出港区次数 | 按货类与吨位段计价 |
| 装卸费 | 元/吨 | 实际装卸吨位 | 按货类计价 |

⚠️ 上述五个费种为**完整枚举**，不得自行增设费种，亦不得使用同义变体名称（如"船闸费""通行费"均不属于本总则的费种）。

### 第五条 【过闸费计费口径】

过闸费按下列口径计收：

1. 过闸费**仅对经平陆运河的航次收取**。航次起点港或终点港位于平陆运河运河节点范围内的，认定为经平陆运河的航次。
2. 非经平陆运河的航次，**不得收取过闸费**。
3. 计费吨位取船舶实际载货吨位，空载航次不计收过闸费。
4. 过闸费费率的吨位分段以船舶载货吨位为准，分段区间为**左闭右开**。

### 第六条 【引航费计费口径】

引航费按下列口径计收：

1. 引航费按引航**服务次数**计收，不以船舶载货吨位计收。
2. 强制引航范围内的船舶，应当接受引航服务并缴纳引航费。
3. 同一航次多次引航的，按实际引航次数分别计收。
4. 因恶劣天气原因中止引航且船舶未进入引航段的，不计收引航费。

### 第七条 【停泊费计费口径】

停泊费按下列口径计收：

1. 停泊费按**停泊吨位与停泊天数**计收，单位为元/吨天。
2. 停泊时间**不足一日的按一日计收**。
3. 停泊天数自船舶靠妥泊位之时起算，至船舶离泊之时止。
4. 停泊吨位取船舶总吨位。

### 第八条 【港杂费与装卸费计费口径】

港杂费与装卸费按下列口径计收：

1. 港杂费按货物**进出港区次数**计收，单位为元/次，按货类大类与吨位段确定费率。
2. 装卸费按**实际装卸吨位**计收，单位为元/吨。
3. 装卸费应当区分装船与卸船作业，同一批货物装、卸各计一次。
4. 货主自备装卸设备并自行完成作业的，仍应缴纳港杂费，装卸费按半价计收。

## 第三章 货类划分与计费依据

### 第九条 【货类划分】

计费所用的货类划分为下列七个大类：

| 货类大类 | 主要包含货物举例 |
|---|---|
| 建材 | 水泥、砂石、混凝土预制件、玻璃、瓷砖 |
| 能源 | 煤炭、石油焦、液化天然气、燃料油 |
| 金属 | 铁矿砂、铝锭、铜材、**钢材及钢材制品**、金属矿石 |
| 农资 | 化肥、粮食、饲料、农药、种子 |
| 化工 | 基础化工原料、涂料、塑料原料 |
| 集装箱 | 标准集装箱及箱内货物 |
| 其他 | 前六类以外的其他货物 |

⚠️ 上表七个大类为**完整枚举**。计费时**不得**增设其他大类名称；粮食归入**农资**，金属矿石归入**金属**，不得单列。

### 第十条 【货类认定争议】

货物所属大类存在争议时，按下列顺序认定：

1. 以运输单证载明的货物名称为准；
2. 单证载明不明确的，以实际货物性质为准；
3. 仍无法认定的，由航运服务中心业务部门核定，并书面告知托运人。

### 第十一条 【危险货物的计费】

危险货物的计费遵循下列规定：

1. 危险货物按其**物理化学性质对应的货类大类**计费，不单独设立"危险品"货类。
2. 危险货物另需缴纳危险货物作业附加费，附加费按相应费种费率的**百分之三十**计收。
3. 危险货物的类别与申报要求，按危险货物运输管理的专项规定执行。

## 第四章 计费时点与查询

### 第十二条 【业务发生日的认定】

费用适用的费率以**业务发生日**为准：

1. 过闸费、引航费的业务发生日为船舶实际过闸日、引航日；
2. 停泊费的业务发生日为停泊起始日；
3. 港杂费、装卸费的业务发生日为作业完成日。

### 第十三条 【生效期规则】

1. 费率规则载明生效起始日与生效终止日。
2. 查询某日适用费率时，业务发生日应当落在**生效起始日（含）至生效终止日（不含）**的区间内。
3. 费率规则未载明生效终止日的，视为长期有效。
4. 同一费种、同一货类、同一吨位段在时间上**不得存在重叠的生效期**。

### 第十四条 【费率查询的四维定位】

查询适用费率时，应当同时确定下列四个维度，任一维度缺失均可能导致查询命中多条或零条规则：

1. **费种**；
2. **货类大类**；
3. **吨位段**；
4. **业务发生日**。

### 第十五条 【费用明细的可审计要求】

1. 每笔费用应当能够追溯到所适用的费率规则。
2. 费用明细应当记录费种、货类、吨位、业务发生日、适用费率、计费金额。
3. 费用记录一经生成不得直接修改；确需更正的，按退费与差错更正的专项规定另行处理。
