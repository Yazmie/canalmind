# 船舶尺度与吃水控制标准

## 第一章 总则

### 第一条 【目的与依据】

为统一平陆运河船闸闸室的技术参数口径，明确船舶过闸的总长、船宽与吃水限值，规范超限船舶的处理方式，保障船舶与船闸设施安全，制定本标准。

本标准依据《船舶过闸管理办法》（PLYH-GZ-2026-001）制定。船舶过闸的申请、预约、闸次编排与现场作业流程，按该办法执行；本标准仅规定尺度与吃水的限值及核验要求，不重复规定过闸流程。

### 第二条 【适用范围】

本标准适用于在马道枢纽船闸、企石枢纽船闸、青年枢纽船闸过闸的干散货船、集装箱船、多用途船、化学品船与驳船，包括尺度核验、吃水核定与超限处理。

### 第三条 【尺度术语】

本标准所用尺度术语含义如下：

1. **船舶总长**，指船舶最前端至最后端的水平距离，以船舶检验证书载明数值为准；
2. **船舶船宽**，指船舶两舷外板之间的最大水平宽度；
3. **满载吃水**，指船舶在登记载重吨满载状态下的最大吃水，即船舶登记信息中的满载吃水；
4. **实际吃水**，指船舶过闸当日实际状态下的吃水，以船舶申报并经核验的数值为准；
5. **闸室有效长度、有效宽度**，指可供船舶安全停泊的闸室内部长度与宽度，即本标准第五条规定值。

## 第二章 船闸与闸室尺度

### 第四条 【枢纽船闸与闸室构成】

1. 平陆运河设三大梯级枢纽，即马道枢纽、企石枢纽与青年枢纽，各枢纽均设**双线船闸**。双线船闸的含义按《术语与定义》（PLYH-GZ-2026-025）确定，即同一枢纽并列布置的两座船闸。
2. 各枢纽双线船闸的闸室编号为 1 号与 2 号；全运河共有闸室 **6 个**，各闸室的技术参数均相同，船舶可以在任一枢纽的任一闸室过闸。
3. 双线布置的用途是一线检修或者故障时另一线仍可维持通行；正常运行状态下，上下行船舶分别使用一线船闸。
4. 各船闸实行 24 小时通航，作业时段不因尺度类别而区别设置。

### 第五条 【闸室尺度与技术参数】

闸室的主要技术参数如下：

| 参数项 | 取值 | 说明 |
|---|---|---|
| 枢纽数量 | 3 个 | 马道枢纽、企石枢纽、青年枢纽 |
| 布置方式 | 双线船闸 | 同一枢纽并列布置两座船闸 |
| 闸室编号 | 1 号、2 号 | 各枢纽一致 |
| 全运河闸室总数 | 6 个 | 三处双线船闸的闸室合计 |
| 闸室有效长度 | 300.0 米 | 各闸室一致 |
| 闸室有效宽度 | 34.0 米 | 各闸室一致 |
| 设计通过能力 | 3000 吨级 | 按设计代表船型核定 |
| 通航时间 | 24 小时 | 全天连续通航 |

1. 上表参数为各闸室的统一取值，不得按枢纽分别适用不同数值。
2. 设计通过能力 3000 吨级系按闸室设计代表船型核定的吨级，**不构成对船舶载重吨的绝对限值**；船舶能否过闸，以本章规定的总长、船宽与吃水限值为准。
3. 船舶总吨位或者载重吨超过设计通过能力的，其过闸条件应当按超限与特种货物运输的专项规定另行核定。

### 第六条 【闸室水位条件的核定】

1. 闸室水位随充泄水过程与上游来水条件变化，本标准**不规定固定的闸室水深刻度**。
2. 船舶可通行的吃水条件，以调度机构在过闸当日核定的水位条件为准，并在调度指令中一并告知。
3. 核定的水位条件低于设计最低通航水位时，允许最大吃水按本标准第九条相应下调。
4. 水位条件的变化不影响本标准第五条规定的闸室有效长度与有效宽度。

## 第三章 船舶尺度限值

### 第七条 【总长限值】

1. 单船过闸的船舶总长不超过 **280.0 米**。
2. 同一闸次编入多艘船舶的，各船总长与船舶之间纵向间距之和不超过 **280.0 米**。
3. 船舶与闸室两端之间的间距均不少于 **10.0 米**。
4. 总长超过 280.0 米的单船，按本标准第四章关于超限船舶的规定办理。

### 第八条 【船宽限值】

1. 单船船宽不超过 **32.5 米**。
2. 同一闸次并列停泊的船舶宽度之和不超过 **30.0 米**，并列船舶与闸室两侧墙面之间的间距之和不少于 **4.0 米**。
3. 闸室内禁止三船并列。
4. 船宽超过 32.5 米的船舶，按本标准第四章关于超限船舶的规定办理。

### 第九条 【吃水限值】

1. 船舶过闸的**允许最大吃水为 4.20 米**，该数值按设计最低通航水位核定。
2. 船舶在过闸全程应当保留不少于 **0.30 米**的富余水深。
3. 核定的水位条件低于设计最低通航水位 **0.50 米**以上时，允许最大吃水下调至 **3.60 米**。
4. 允许最大吃水在任何情况下不得超过 4.50 米；实际吃水超过 4.20 米的船舶，按本标准第四章关于超限船舶的规定办理。
5. 船舶申报的吃水数值应当保留至小数点后两位。

### 第十条 【代表船型尺度】

各船型登记载重吨与代表尺度如下，供申报与核验时参照：

| 船型 | 登记载重吨区间（吨） | 代表总长（米） | 代表船宽（米） | 代表满载吃水（米） |
|---|---|---|---|---|
| 干散货船 | 1500–5500 | 65.0–95.0 | 12.0–16.0 | 3.20–4.20 |
| 集装箱船 | 2000–5000 | 70.0–100.0 | 12.8–16.0 | 3.20–4.10 |
| 多用途船 | 1500–4000 | 62.0–90.0 | 12.0–15.5 | 3.00–4.00 |
| 化学品船 | 1000–3000 | 55.0–80.0 | 10.5–14.0 | 2.80–3.80 |
| 驳船 | 800–2000 | 45.0–70.0 | 9.0–12.5 | 2.20–3.40 |

1. 上表载重吨区间为船舶登记的参照区间，**不作为过闸可行性的判定依据**。
2. 表内代表尺度取自各船型的常见取值，实际船舶以船舶检验证书载明数值为准。

### 第十一条 【尺度核验】

1. 船舶尺度核验以船舶检验证书载明的总长、船宽、满载吃水与业务系统登记数据为基础，二者不一致时以船舶检验证书为准，并应当先更正登记数据。
2. 船舶应当在过闸申报时如实申报实际吃水；申报的吃水数值与核定水位条件下的允许最大吃水比对后，确定是否准予过闸。
3. 航运服务中心可以按不低于 **5%** 的比例对申报船舶实施现场抽测，抽测内容包括吃水标尺读数与船宽。
4. 船舶登记信息发生变更的，应当在变更完成后 **5 个工作日**内更新业务系统登记数据。
5. 现场抽测发现申报吃水与实际吃水不一致的，按本标准第十五条处理。

## 第四章 超限船舶处理

### 第十二条 【超限船舶的认定】

船舶符合下列任一情形的，认定为超限船舶：

| 超限类别 | 认定标准 | 处理方式 |
|---|---|---|
| 一般超限 | 总长超过 280.0 米但不超过 300.0 米 | 专项审批后，以单线单船方式过闸，不得双船同闸 |
| 一般超限 | 船宽超过 32.5 米但不超过 34.0 米 | 专项审批后，以单线单船、居中系泊方式过闸，两侧不得并列他船 |
| 一般超限 | 实际吃水超过 4.20 米但不超过 4.50 米 | 减载后可以申请过闸 |
| 严重超限 | 总长超过 300.0 米 | 不予过闸 |
| 严重超限 | 船宽超过 34.0 米 | 不予过闸 |
| 严重超限 | 实际吃水超过 4.50 米 | 不予过闸，应当减载后重新申报 |

同一船舶同时符合两项以上一般超限情形的，按其中最高一项标准适用审批要求。

### 第十三条 【超限过闸的专项审批】

1. 超限船舶的专项审批，按《超限与特种货物运输规定》（PLYH-GZ-2026-012）办理：申请应当在预计过闸时间**前 7 个工作日**提交；因抢险、救灾等紧急情形需要的，可以在预计过闸时间**前 24 小时**提交。
2. 专项申请应当载明船舶尺度、实际吃水、载货情况、拟通过闸室以及拟采取的减载或者分驳措施。
3. 受理机构应当自收到齐备材料之时起 **5 个工作日**内作出审批结论；属于紧急情形的，审批时限为 **12 小时**。需要组织现场核验的，核验时间不计入审批时限，但应当书面告知申请人。
4. 专项审批实行**一航次一批**，审批文书载明的有效期不超过 **15 日**，仅对申请载明的航次、闸室与通行方式有效。
5. 未取得专项审批的超限船舶，不予编排闸次。

### 第十四条 【减载、分驳与转载】

1. 因吃水超限需要减载的，应当在航运服务中心指定的锚地或者作业区进行，不得在闸室或者引航道内进行减载作业。
2. 减载后的实际吃水不超过 4.20 米，并保留不少于 0.30 米的富余水深。
3. 同一船舶分驳为两艘以上船舶过闸的，分驳后各船的尺度与吃水在本标准限值以内的，按普通船舶申报；仍超出限值的，应当按规定办理专项审批。
4. 减载、分驳与转载产生的装卸、堆存费用，按相应费种的费率表计收。
5. 减载后的实际吃水由承运人申报，航运服务中心核验后方可编排闸次。

### 第十五条 【违规超限的处理】

1. 未取得专项审批擅自进闸的超限船舶，责令退出闸室，并自认定之日起 **15 日**内不予受理其过闸申报。
2. 申报吃水或者尺度信息不实，经现场抽测确认的，自认定之日起 **30 日**内不予受理其过闸申报。
3. 因超限或者申报不实造成船闸设施损坏的，应当承担赔偿责任。
4. 拒不退出闸室或者拒不配合现场核验的，移交海事管理机构依法处理。
