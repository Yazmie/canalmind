| **①-a `limit` 超上限** | 桩发 `limit=10000` ⇒ `status=DEGRADED`、**数据层未被调用**、trace：`校验错误：must have a maximum value of 50`；对照 `limit=50` ⇒ `OK` 且**照常执行** | ⛔ **"SchemaGate 没拦住、照常执行"不成立于今天**——闸门拦住了。⚠️ 残留：状态是 `DEGRADED`（`SCHEMA_INVALID`）而非数据集要的 `REJECTED` |
| **①-b `group_by` 注入** | 桩发 `货类); DROP TABLE waybill;--` ⇒ `status=DEGRADED`、**数据层未被调用**、trace：`does not have a value in the enumeration ["货类","货种","起运港","目的港","客户","月份","无"]` | ⛔ **注入今天被执行层拦住了**（`DROP TABLE` 从未到达 SQL）；⚠️ 残留同上：判为 `DEGRADED` 而非 `REJECTED`。第二道防线（`StructuredQueryRepository` 的 `GROUP_EXPR` 白名单，L95–101）在闸门之后，本次**未触达** |
